# AGENTS.md

Правила работы с этим проектом для AI-ассистентов.

## Формат ответа

- **По умолчанию** — обычные markdown-блоки кода (` ```rust ... ``` `).
- **Формат `FILE ... END FILE`** — использовать ТОЛЬКО когда пользователь
  явно попросил: «пиши файлами», «давай в формат», «выгружай» и т.п.
- Не инициировать формат `FILE ... END FILE` самостоятельно, даже если
  в проекте есть скрипт, который его парсит.

## Протокол вставки

Скрипт `scripts/paste_unpack.rs` умеет принимать блоки:

    FILE путь/к/файлу
    ====
    <содержимое>
    ====
    END FILE

    DELETE путь/к/файлу

Но это **приёмник**, а не приглашение. Пока пользователь не сказал
«поехали» — отвечаем обычно.

## Что можно/нельзя трогать

- Редактор (`src/`) — только по явному запросу, конкретный файл,
  конкретная задача. Никаких «заодно улучшу».
- Скрипты (`scripts/`) — по явному запросу.

## Стиль

- Минимальные диффы. Не рефакторить то, о чём не просили.
- Если сомневаешься — спроси, не делай.
